# Violet Virtual Assistant

Violet is a virtual assistant that helps you automate your daily tasks, such as scheduling, sending emails, watching TV shows, web scraping, etc. 

## Features

- Uses the Whisper ASR engine for speech recognition
- Integration with popular tools and services such as Gmail, Spotify, etc.
- Customizable voice commands and responses

## Getting Started

To get started with Violet, you will need to do the following:

1. Clone this repository to your local machine.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Set up the necessary API keys required for the services you want to use.
4. Run the main.py script to start the virtual assistant.

## Usage

Violet is designed to be easy to use and understand. You can interact with Violet by speaking to it in natural language or typing commands into the command line interface.

Here are some examples of commands you can use with Violet:

- "Hey violet, what are my tasks for today?"
- "Hey violet, Send an email to Zack with the subject 'Meeting Reminder'"
- "Hey violet, remind me to buy milk tomorrow at 5pm"
- "Hey violet, play my favorite songs on Spotify"
- "Hey violet, can you open chrome for me?"
